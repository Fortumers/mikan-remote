# Rust API client: этап 1

Статус: исходники, Rust-сборка и подключение к установленной панели ещё не проверены. Интерфейс по-прежнему работает на mock-данных; кнопка подключения пока не подключена к командам.

Добавлены команды connect_panel(address, apiKey), disconnect_panel(), get_overview(), get_traffic(). Вызов из React через Tauri invoke; потребуется @tauri-apps/api на следующем этапе. Возвращается исходный JSON Mikan без предположений о его схеме.

Адрес: полный HTTPS-адрес админки с секретным путём, например https://panel.example.com/secret-admin/ — без api/v1, query и fragment. Ключ: API с правами чтения. Не публиковать реальный адрес и ключ в GitHub.

Авторизация: Authorization: Bearer. Используются только GET stats/overview и stats/traffic. Проверка подключения получает overview и сохраняет новое подключение только при успехе. При неудачной смене старое подключение остаётся активным.

Ключ хранится только в памяти, не записывается в файлы. Проверка TLS включена, перенаправления отключены; сетевые ошибки возвращаются без URL и ключа. Отключение удаляет сохранённое подключение, но уже выполняющиеся запросы могут завершиться.

Проверка после установки Rust и C++ Build Tools:

```powershell
cd src-tauri
cargo test
cargo check
cd ..
npm.cmd run tauri dev
```
