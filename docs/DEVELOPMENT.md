# PumbaNET Admin — первый этап

Статус: исходный каркас; сборка и запуск ещё не проверены. Данные вымышлены, Mikan не подключён.

## Веб-интерфейс

Нужен Node.js с npm.

```sh
npm install
npm run dev
npm run build
```

## Windows / Tauri

Дополнительно нужны Rust, Microsoft C++ Build Tools и WebView2.

```sh
npm run tauri dev
npm run tauri build
```

Создание установщика пока отключено (`bundle.active=false`). После проверки сборки добавим иконки, упаковку и CI.

## Архитектура

`src/services/dashboard.ts` — контракт DashboardService и демонстрационная реализация. Экран не обращается напрямую к Mikan. Серверный адаптер появится отдельно.

Все экраны доступны: главная, серверы, пользователи с поиском, платежи, события, настройки. Настройки подключения — только макет, секреты вводить нельзя.
