# Mikan Remote — разработка

Актуальные команды запуска, проверки и упаковки находятся в [руководстве](GUIDE.md).

Точка входа src/main.tsx напрямую запускает RealApp. Переключателя режимов нет. Содержимое прежнего демонстрационного экрана и сервиса вымышленных данных удалено; файлы пока оставлены как пустые модули.

Рабочие разделы получают данные через Tauri invoke и Rust-клиент. Создание и редактирование пользователей используют отдельные команды с подтверждением.

После изменения имени пакета локальные lock-файлы необходимо синхронизировать обычной установкой npm и сборкой Cargo. Не редактируйте зависимости вручную и не удаляйте весь target без необходимости.

Переименование ещё не является полной очисткой всех старых технических заметок, истории Git и опубликованных бинарных файлов. Перед релизом проверьте остаточные строки и новую сборку.
