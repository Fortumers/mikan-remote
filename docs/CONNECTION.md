# Экран подключения

Статус: код добавлен, сборка новой версии и подключение к реальной панели ещё не проверены.

Верхний переключатель разделяет диагностику API и демо-дашборд. Демо-дашборд по-прежнему показывает только вымышленные данные. Экран подключения показывает исходный JSON, не преобразует его в карточки.

После обновления исходников:

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run tauri dev
```

Последняя команда требует Rust/MSVC/C++ Build Tools и WebView2. В браузерном режиме подключение отключено.

В приложении указать конечный HTTPS-адрес админки вместе с секретным путём, но без api/v1. Ввести API-ключ чтения локально, нажать «Проверить и подключить». Затем запросить трафик. При ошибке поля и старый успешный ответ не означают новое успешное подключение: следить за сообщением ошибки. Неудачная замена оставляет предыдущее подключение активным. Отключение очищает ответы и сохранённое подключение; адрес остаётся в форме.

Нет сохранения в localStorage или файлы. Поле ключа очищается после успешного подключения, а ключ остаётся в памяти Rust до отключения/закрытия приложения. Не публиковать ключи, секретные пути и ответы с клиентскими данными.
