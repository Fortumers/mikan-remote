# Mikan Remote — иконки

app-icon.svg — исходная иконка: оранжевая M на графитовом фоне.

Перед Tauri dev/build настроена генерация платформенных иконок. Отдельно, из корня проекта:

```powershell
npm.cmd run tauri -- icon app-icon.svg
```

После изменения иконки выполните новую сборку. Старый опубликованный установщик и старые локальные бинарные файлы не меняются автоматически.
