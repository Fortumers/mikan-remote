# Read-only collections

Реальные GET users, nodes, payments открываются через боковые пункты Пользователи, Серверы, Платежи. Дублирующая верхняя API-навигация удалена. Переключатель демо/рабочего режима не является навигацией разделов.

По сообщению пользователя предварительные API-таблицы работают. Эта новая интеграция меню ещё не проверена сборкой и запуском.

Распознаётся массив или объект с items-массивом. Другие форматы отклоняются явно. Таблица показывает простые поля ответа. Загружается одна страница API; поиск локальный, серверная пагинация пока не добавлена. Суммы платежей остаются в исходных единицах API, без расчёта выручки.

Настройки подключения остаются смонтированы при переключении разделов. При открытии API-раздела запрос выполняется заново. События — локальный журнал, не серверный аудит. Аудит sessionOnly, история трафика и управление не реализованы.

После обновления файлов: npm.cmd run build, затем npm.cmd run tauri dev. Ключи и клиентские данные не публиковать.
