# Read-only collections — предварительная интеграция

Добавлены GET users, nodes, payments через whitelist команды get_collection. Никаких изменений панели. Сборка и запросы этих разделов ещё не проверены.

Временная верхняя навигация «Пользователи API», «Серверы API», «Платежи API» открывает реальные таблицы. Старые пункты бокового меню пока остаются заглушками; это не окончательная интеграция меню.

Распознаётся массив или объект с items-массивом. Иные ответы отклоняются явно, не интерпретируются как пустой список. Поля таблицы берутся из ответа, сложные поля не разворачиваются. Это временный просмотр, не окончательные типизированные модели.

Запрашивается одна страница с параметрами API по умолчанию. Поиск локальный; серверная пагинация и фильтры ещё не реализованы. Суммы платежей не конвертируются и не суммируются, пока не подтверждены единицы и валюты.

Аудит в оригинальной Mikan отмечен sessionOnly и не реализован с API-ключом. История трафика и управление также не добавлены. Локальные события главной не являются серверным аудитом.

После обновления файлов: npm.cmd run build, затем npm.cmd run tauri dev. API-ключ и клиентские ответы не публиковать. Все источники данных нужно проверить на установленной версии панели.
