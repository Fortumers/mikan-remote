# Рабочая главная по образцу демо

Статус: исходники; новая сборка и соответствие установленной панели ещё не проверены.

Четыре карточки: пользователи, активные пользователи, сумма входящего/исходящего трафика возвращённых точек, доступные ноды по status=ok. Выручка не подставляется: источник и единицы финансовой сводки ещё не подтверждены.

get_traffic использует стандартный range=7d оригинальной Mikan. Ожидается {points:[{t,up,down}]}. При несовпадении схемы показывается ошибка. Пустая история не рисуется из mock-данных. Сумма относится только к возвращённым точкам. Линия соединяет точки, но пропущенные интервалы не дополняются нулями.

GET nodes ожидает массив или items. Статус ok/error/unknown, cpu_percent, mem_used/mem_total, conns взяты из схемы оригинальной Mikan. Это сохранённая проверка панели; свежесть здоровья ноды не подтверждается временем получения списка. При status не ok показатели нагрузки не выводятся.

Обновление трёх блоков параллельное; каждый имеет собственную ошибку. Неудачный запрос очищает данные своего блока. Автообновление по умолчанию выключено, опция 30 секунд; после ухода с главной таймер отключается. Запросы в полёте не отменяются, результат после размонтирования не записывается.

Подключение остаётся в Настройках; боковое меню единственное. События теперь явно показывают только локальные переходы между разделами, не API-аудит.

Проверка: npm.cmd run build; npm.cmd run tauri dev. Подключиться, открыть Главную, проверить график, CPU/память и ошибки при отключении сети. Не публиковать клиентские данные.
