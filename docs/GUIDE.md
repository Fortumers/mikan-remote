# Mikan Remote — руководство

[К странице проекта](../README.md)

## Подключение

Адрес — полный HTTPS-адрес админки с секретным путём, без `api/v1`, query и fragment. Вымышленный пример: `https://panel.example.com/secret-admin/`.

Для просмотра нужен API-ключ чтения, для изменений — права записи. Полный ключ не заменяет административную сессию для операций, которые требуют её.

Ключ хранится в памяти текущего запуска. После перезапуска подключитесь заново. Проверка TLS включена, перенаправления отключены.

## Пользователи

Создание: «Пользователи» → «Список и создание». Имя, необязательный контакт, тариф и подтверждение. Срок и лимиты берутся из тарифа.

Редактирование: найдите ID в списке, откройте «Редактировать по ID» и загрузите пользователя. Отправляются только выбранные изменения. Эта форма не выполняет смену тарифа, срока или сброс использованного трафика.

1 ГБ = 1 000 000 000 байт. Безлимит включается через «Снять лимит», а не значением ноль. Лимит устройств — 1–100.

Перед записью выполняется повторная проверка загруженных полей, не атомарная блокировка. Если ответ потерян, сначала загрузите пользователя заново: операция могла выполниться.

## Сборка

Нужны Node.js/npm, Rust с Windows MSVC toolchain, Microsoft C++ Build Tools с компонентами C++ и WebView2. Готовому приложению Node.js и Rust не нужны; WebView2 runtime должен быть доступен.

Из корня проекта, содержащего package.json:

```powershell
npm.cmd install
npm.cmd run tauri -- icon app-icon.svg
npm.cmd run build
cargo test --manifest-path .\src-tauri\Cargo.toml
npm.cmd run tauri dev
```

Выполняйте команды по очереди, проверяя успешное завершение. Проверки новой переименованной версии ещё необходимо выполнить.

### Установщик

```powershell
npm.cmd run tauri -- build --bundles nsis
```

Стандартная папка: `src-tauri/target/release/bundle/nsis/`.

### EXE

```powershell
npm.cmd run tauri -- build --no-bundle
```

Ожидаемый стандартный файл после переименования Rust-пакета: `src-tauri/target/release/mikan-remote.exe`.

Идентификатор приложения изменён на `app.mikanremote.desktop`. Не считайте новый установщик гарантированным обновлением старой установки: проверьте установку и удалите старое приложение отдельно при необходимости. Старые бинарные файлы в локальном target могут остаться после сборки — публикуйте только новый результат.

## Ошибки

- Отказ в доступе при замене EXE: закройте работающий экземпляр перед сборкой.
- Неизвестный хост при загрузке NSIS: проверьте доступ к загрузкам GitHub. Сам EXE мог уже собраться.
- Предупреждение Vite о chunk больше 500 кБ само по себе не означает ошибку сборки.

## Безопасность

Не публикуйте API-ключи, пароли, реальный секретный путь, ссылки подписок и клиентские данные. Скрывайте их на скриншотах. При утечке ключа отзовите его.

Не загружайте node_modules, src-tauri/target, личные настройки и .env с секретами в исходники. Установщики прикрепляются к Releases. Не публикуйте подробности уязвимости в открытом issue.
