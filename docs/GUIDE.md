# Руководство PumbaNET Admin

[Вернуться к проекту](../README.md)

## Подключение

В рабочем режиме откройте «Настройки». Адрес — полный HTTPS-адрес админки с секретным путём, без `api/v1`, query и fragment. Вымышленный пример:

```text
https://panel.example.com/secret-admin/
```

Для просмотра нужен API-ключ чтения, для изменений — права записи. Некоторые операции Mikan требуют административной сессии: полный ключ не заменяет её.

Ключ хранится в памяти текущего запуска; после перезапуска подключение выполняется заново. Проверка TLS включена, перенаправления отключены.

## Пользователи

Создание: «Пользователи» → «Список и создание». Укажите имя, необязательный контакт, тариф и подтвердите запрос. Срок и лимиты берутся из тарифа.

Редактирование: найдите ID в списке, откройте «Редактировать по ID» и загрузите пользователя. Отправляются только выбранные поля. Тариф, срок и использованный трафик эта форма не сбрасывает.

1 ГБ = 1 000 000 000 байт. Для безлимита выбирайте «Снять лимит»; ноль — нулевой лимит. Лимит устройств в редакторе — 1–100.

Перед записью повторно проверяются загруженные поля. Это не атомарная блокировка. При потере ответа сначала загрузите пользователя заново: изменения могли примениться.

## Запуск из исходников

Нужны Node.js/npm, Rust с Windows MSVC toolchain, Microsoft C++ Build Tools с компонентами C++ и WebView2. Для готового приложения Node.js и Rust не требуются; WebView2 runtime должен быть доступен.

Из корня проекта:

```powershell
npm.cmd install
npm.cmd run tauri -- icon app-icon.svg
npm.cmd run tauri dev
```

Проверки:

```powershell
npm.cmd run build
cargo test --manifest-path .\src-tauri\Cargo.toml
```

## Релизная сборка

Установщик:

```powershell
npm.cmd run tauri -- build --bundles nsis
```

Стандартный каталог: `src-tauri/target/release/bundle/nsis/`.

EXE без установщика:

```powershell
npm.cmd run tauri -- build --no-bundle
```

Стандартный файл: `src-tauri/target/release/pumbanet-admin.exe`.

### Ошибки сборки

- Отказ в доступе при удалении EXE: закройте приложение перед сборкой. Работающий файл может быть заблокирован Windows.
- Неизвестный хост при загрузке NSIS: проверьте доступ к загрузкам GitHub. Сам EXE мог уже успешно собраться.
- Предупреждение Vite о chunk больше 500 кБ само по себе не означает ошибку сборки. Проверяйте итоговый результат команды.

## Безопасность и отчёты

Не публикуйте ключи, пароли, секретный путь панели, ссылки подписок и клиентские данные. Скрывайте их на скриншотах. Используйте ключ чтения, если изменение данных не требуется.

Не загружайте в репозиторий `node_modules`, `src-tauri/target`, личные настройки и `.env` с секретами. Установщики прикрепляются к Releases.

В отчёте укажите версии приложения и Mikan, шаги воспроизведения и обезличенный текст ошибки. Не размещайте секреты или подробности уязвимостей в публичных Issues. При утечке ключа отзовите его в панели.
