## Интерфейс для повседневной работы с Mikan

PumbaNET Admin соединяет обзор сервиса и основные операции с пользователями в отдельном Windows-приложении. Данные рабочего режима поступают из вашей панели [Mikan](https://github.com/Miroshka000/mikan). Демо-режим существует отдельно и использует вымышленные данные.

### 01 — Мониторинг

Показатели сервиса, история входящего и исходящего трафика, последнее состояние нод по данным панели. Ручное обновление или обновление главной каждые 30 секунд.

### 02 — Пользователи

Просмотр списка и создание пользователя по существующему тарифу. Редактирование по ID: имя, контакт, заметка, лимиты трафика и устройств, включение и отключение доступа.

### 03 — Подтверждение изменений

Перед записью отображаются пользователь и выбранные изменения. При потере ответа приложение предупреждает о неопределённом результате — запрос не повторяется автоматически.

## Установка

1. Откройте [предварительный релиз](https://github.com/Fortumers/pumbanet-admin/releases/tag/pre).
2. Скачайте Windows x64 установщик `-setup.exe` из Assets и установите приложение. Если файла нет в Assets, загрузка установщика ещё не опубликована.
3. Выберите рабочий режим и подключите панель в «Настройках».

Нужны полный HTTPS-адрес админки с секретным путём и собственный API-ключ. Для просмотра — права чтения; для создания и редактирования — права записи. Адрес и ключ не публикуйте.

[Подключение, сборка и устранение ошибок →](docs/GUIDE.md)

## Статус проекта

Предварительная версия. Самостоятельный проект, не официальный клиент Mikan.

Сейчас приложение не заменяет всю веб-панель: смена тарифа и срока, дополнительные пакеты трафика, управление тарифами и конфигурацией серверов ещё не реализованы. Серверы и платежи доступны для просмотра. Локальные события — не серверный аудит. Полученный список не гарантирует загрузку всех страниц API.

Совместимость со всеми версиями Mikan не заявляется. Повторная проверка данных перед редактированием не является атомарной блокировкой.
