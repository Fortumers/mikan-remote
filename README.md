## О проекте

PumbaNET Admin — отдельное приложение для работы с [Mikan](https://github.com/Miroshka000/mikan). Главная показывает показатели сервиса, историю трафика и состояние нод. В разделе пользователей можно создать пользователя по тарифу или изменить отдельные параметры существующего.

Интерфейс выполнен в тёмной теме с оранжевыми акцентами. Рабочий режим получает данные из API панели; отдельный демо-режим предназначен для знакомства с интерфейсом и содержит вымышленные показатели.

> Проект развивается. Это не полная замена веб-панели Mikan. Успешная сборка установщика не гарантирует совместимость со всеми версиями панели.

## Возможности

| Раздел | Что доступно сейчас |
| --- | --- |
| Главная | Пользователи, активные пользователи, график трафика за период, количество доступных нод |
| Серверы | Просмотр нод, последнего состояния по данным панели, CPU, памяти и соединений |
| Пользователи | Просмотр списка и создание пользователя по существующему тарифу |
| Редактор | Загрузка по ID; имя, контакт, заметка, лимит трафика, лимит устройств, включение и отключение |
| Платежи | Просмотр данных API без самостоятельной конвертации сумм и расчёта выручки |
| Настройки | Подключение по HTTPS-адресу панели и API-ключу |
| Обновление | Ручное обновление главной и опциональное обновление каждые 30 секунд |

### Что пока не добавлено

- Смена тарифа и срока подписки существующего пользователя.
- Управление дополнительными пакетами гигабайтов и пулами трафика.
- Создание и редактирование тарифов в приложении.
- Изменение конфигурации серверов и подключений.
- Серверный аудит: раздел событий показывает только локальные переходы.
- Гарантия полного списка пользователей: учитывайте ограничения и пагинацию установленной панели.

## Установка

1. Откройте [предварительный релиз](https://github.com/Fortumers/pumbanet-admin/releases/tag/pre).
2. В блоке Assets скачайте приложенный Windows x64 установщик с окончанием `-setup.exe`. Если установщик ещё не приложен, готовой загрузки на странице пока нет.
3. Закройте ранее запущенный PumbaNET Admin и выполните установку.
4. Запустите установленное приложение и выберите рабочий режим.
5. В настройках укажите HTTPS-адрес панели и собственный API-ключ.

Для использования готового приложения Node.js и Rust не нужны. Приложение использует WebView2; на компьютере должен быть доступен соответствующий runtime.

### Подключение к Mikan

Адрес — полный HTTPS-адрес админки с её секретным путём, без `api/v1`, query-параметров и fragment. Пример с вымышленным адресом:

```text
https://panel.example.com/secret-admin/
```

Для мониторинга достаточно прав чтения. Создание и редактирование пользователей требуют прав записи. Некоторые операции Mikan требуют административной сессии и не становятся доступными только из-за полного API-ключа.

Ключ хранится в памяти текущего запуска. После перезапуска подключение потребуется выполнить заново. Проверка TLS включена, перенаправления HTTP-клиента отключены.

## Управление пользователями

### Создать

Откройте «Пользователи» → «Список и создание». Заполните имя, при необходимости контакт, выберите тариф из панели, проверьте данные и подтвердите создание. Срок и лимиты берутся из выбранного тарифа.

### Редактировать

Откройте «Редактировать по ID», загрузите пользователя и измените необходимые поля. Перед отправкой приложение покажет перечень изменений и конкретного пользователя.

- В запрос отправляются только выбранные изменения.
- Лимит ГБ переводится в байты: 1 ГБ = 1 000 000 000 байт.
- Для безлимита выбирайте «Снять лимит»; нулевой лимит не означает безлимит.
- Перед записью выполняется повторная проверка загруженных полей. Это предварительная проверка, не атомарная блокировка.
- При потере ответа изменения могли примениться. Сначала загрузите пользователя заново, не повторяйте запрос вслепую.

## Сборка из исходников

Нужны Node.js/npm, Rust с Windows MSVC toolchain, Microsoft C++ Build Tools с компонентами разработки C++ и WebView2. Команды выполняются из корня проекта, где находится `package.json`.

```powershell
npm.cmd install
npm.cmd run tauri -- icon app-icon.svg
npm.cmd run tauri dev
```

### Проверки

```powershell
npm.cmd run build
cargo test --manifest-path .\src-tauri\Cargo.toml
```

### Windows-установщик

```powershell
npm.cmd run tauri -- build --bundles nsis
```

Стандартная папка результата:

```text
src-tauri/target/release/bundle/nsis/
```

### EXE без установщика

```powershell
npm.cmd run tauri -- build --no-bundle
```

Стандартный путь:

```text
src-tauri/target/release/pumbanet-admin.exe
```

Перед повторной сборкой закройте запущенный EXE: Windows может блокировать его замену. Для первой упаковки NSIS требуется доступ к загрузкам GitHub. Предупреждение Vite о размере chunk само по себе не означает, что сборка завершилась ошибкой.

## Безопасность

- Не публикуйте API-ключи, пароли, реальный секретный путь панели и ссылки подписок.
- Перед загрузкой скриншотов скрывайте клиентские данные.
- Используйте права чтения, если управление пользователями не требуется.
- Не загружайте в репозиторий `node_modules`, `src-tauri/target`, личные настройки или `.env` с секретами. Установщики публикуются как вложения Releases.
- Не размещайте подробности уязвимости или действующие секреты в публичном issue. При утечке ключа отзовите его в панели.
