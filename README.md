## Панель рядом. Работа — в одном окне.

PumbaNET Admin — десктопный помощник для [Mikan](https://github.com/Miroshka000/mikan). Следите за сервисом, создавайте пользователей по тарифу и меняйте лимиты без переключения между разделами веб-панели.

Тёмный интерфейс. Оранжевые акценты. Данные из вашей панели.

> [!NOTE]
> Предварительная версия для Windows x64. Это самостоятельный проект, а не официальный клиент Mikan и не полная замена веб-панели.

## Начать работу

### 1. Установите приложение

Откройте [страницу предварительного релиза](https://github.com/Fortumers/pumbanet-admin/releases/tag/pre) и скачайте приложенный файл `-setup.exe` из Assets. Закройте ранее запущенный экземпляр и выполните установку. Если установщик ещё не прикреплён к релизу, готовой загрузки там пока нет.

### 2. Подключите свою панель

Выберите рабочий режим. В «Настройках» укажите полный HTTPS-адрес админки с секретным путём и собственный API-ключ.

```text
https://panel.example.com/secret-admin/
```

Это вымышленный пример. Не добавляйте к адресу `api/v1`, query-параметры или fragment. Для просмотра нужны права чтения; для создания и редактирования — права записи.

### 3. Работайте с пользователями

В разделе «Пользователи» доступны «Список и создание» и «Редактировать по ID». Сначала проверьте подключение и загрузку данных, затем выполняйте изменения.

## Возможности и границы

| Область | Реализовано |
| :--- | :--- |
| Обзор | Пользователи, активные пользователи, трафик за период, доступные ноды |
| График | История входящего и исходящего трафика из API |
| Ноды | Просмотр последнего состояния, CPU, памяти и соединений |
| Создание | Пользователь по существующему тарифу Mikan |
| Редактирование | Имя, контакт, заметка, лимит ГБ и устройств, включение/отключение |
| Платежи | Просмотр данных API без самостоятельного расчёта выручки |
| Обновление | Вручную или каждые 30 секунд на главной |

Демо-режим показывает вымышленные данные и существует отдельно от рабочего режима. События приложения — локальные переходы, не серверный аудит. Загрузка списка не гарантирует, что получены все страницы API.

<details>
<summary>Что пока остаётся в веб-панели Mikan</summary>

- Смена тарифа и срока подписки существующего пользователя.
- Дополнительные пакеты гигабайтов и пулы трафика.
- Создание и редактирование тарифов.
- Изменение конфигурации серверов и подключений.
- Операции, требующие административной сессии, а не API-ключа.

Совместимость со всеми версиями Mikan не заявляется. Успешная сборка установщика не является полной проверкой интеграции.

</details>

## Изменения под контролем

Редактор загружает пользователя по ID и показывает изменения перед подтверждением. Отправляются только выбранные поля.

- 1 ГБ = 1 000 000 000 байт. Нулевой лимит не означает безлимит: используйте «Снять лимит».
- Перед сохранением повторно проверяются загруженные поля. Это предварительная проверка, не атомарная блокировка.
- При потере ответа операция могла завершиться. Загрузите пользователя заново перед повтором.

> [!IMPORTANT]
> Не публикуйте ключи, пароли, секретный путь панели, ссылки подписок и клиентские данные. API-ключ хранится в памяти текущего запуска; после перезапуска подключение нужно выполнить заново.

## Для разработчиков

Tauri 2 · React · TypeScript · Vite · Rust · Recharts

<details>
<summary>Запуск и проверки</summary>

Нужны Node.js/npm, Rust с Windows MSVC toolchain, Microsoft C++ Build Tools с компонентами C++ и WebView2. Для готового приложения Node.js и Rust не требуются; WebView2 runtime должен быть доступен.

Из корня репозитория:

```powershell
npm.cmd install
npm.cmd run tauri -- icon app-icon.svg
npm.cmd run tauri dev
```

Проверки:

```powershell
npm.cmd run build
cargo test --manifest-path .\src-tauri\Cargo.toml
```

</details>

<details>
<summary>Сборка Windows-установщика и EXE</summary>

Установщик NSIS:

```powershell
npm.cmd run tauri -- build --bundles nsis
```

Стандартный каталог: `src-tauri/target/release/bundle/nsis/`.

EXE без установщика:

```powershell
npm.cmd run tauri -- build --no-bundle
```

Стандартный файл: `src-tauri/target/release/pumbanet-admin.exe`.

Закройте работающий EXE перед новой сборкой: Windows может блокировать замену. Для первой упаковки NSIS нужен доступ к загрузкам GitHub. Предупреждение Vite о размере chunk само по себе не означает ошибку сборки.

</details>

<details>
<summary>Подключение и безопасная публикация</summary>

HTTPS и проверка TLS обязательны в текущем клиенте; перенаправления отключены. Используйте ключ чтения, когда изменения не нужны. Полный API-ключ не заменяет административную сессию для session-only операций.

В репозиторий не следует загружать `node_modules`, `src-tauri/target`, личные настройки и `.env` с секретами. Установщики прикрепляются к Releases.

Перед скриншотами и отчётами удаляйте клиентские данные. Не публикуйте секреты или подробности уязвимостей в открытом issue. При утечке ключа отзовите его в панели.

</details>
